# LJ Fresh Stylez Website

## About the Website

LJ Fresh Stylez is a barber shop website created to provide customers with information about the barber shop, its services and grooming products.

The website is designed to give customers an easy way to learn about LJ Fresh Stylez, view the services offered, enquire about services and find the contact details and location of the barber shop.

## Website Pages

The website contains the following pages:

- Home
- About Us
- Services
- Products
- Enquiry
- Contact Us

## Services

LJ Fresh Stylez provides a variety of barbering and grooming services, including:

- Classic Haircuts
- Low Fades
- Mid Fades
- High Fades
- Taper Fades
- Beard Grooming
- Hair Styling
- General Grooming

## Products

The website also provides information about grooming products, including:
